Run `python verify_portable_test.py` from this folder with NumPy installed. It recomputes all 18 saved-prediction confusion matrices, accuracy/macro-F1 and the prespecified patient-cluster bootstrap. No raw images, model weights, PyTorch, GPU or network are needed. This checks saved numerical evidence; it does not independently prove model inference without the local checkpoints. The cluster interval is descriptive and conditions on these three seeds. The fuller independent verification also checks all per-class metrics and calibration within the recorded tolerances.
